# Dailies note template

Fill in each field from the script info and the render result. Keep notes to the facts; the
supervisor reads dozens of these.

```
SHOT:      <shot>
VERSION:   <script version>
FRAMES:    <first>-<last> (<frame count> frames)
OUTPUT:    <output path>
CHANGES:   <one line per change made in this version>
FOR:       <what the artist wants feedback on, or "general review">
```
